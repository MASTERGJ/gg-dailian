# gg-dailian / gg代练

外部素材的证据化理解、价值蒸馏与资产化交付系统。将视频、网页、截图、音视频参考资料、本地素材转化为证据支撑的理解、价值判断、可复用结构和用户可交付物。

## 这是什么

gg-dailian 是一个面向 AI Agent 的公共技能包，用于外部素材的证据化理解与价值蒸馏。它将视频分析、网页研究、视觉证据处理、产物交付整理成可复用的 Agent 指令、参考方法、模板和示例。

这不是一个 prompt 集合。它是一个紧凑的源情报操作系统，有证据边界、源类型路由、价值阈值门和产物输出契约：

```
源素材 → 理解 → 价值判断 → 可复用模式 → 用户可交付物
```

## 与普通分析工具的区别

- **证据先行**：判断要回到来源、截图、时间戳、提取方式
- **源类型路由**：视频、网页、截图、文本 —— 每种有独立的证据采集路径
- **价值阈值门**：不是每个素材都值得出大报告。薄素材给紧凑结论
- **产物驱动**：SOP、操作手册、教程、展示页、知识笔记、技能草稿
- **Agent 可移植**：Markdown-skill-capable 的 Agent 都能适配
- **公开/私有安全**：公开示例用合成或已授权材料，真实项目留本地

## 快速开始

### 1. 按素材类型选择

| 素材 | 你能得到什么 |
|------|------------|
| YouTube / Bilibili 链接、本地视频 | 带证据索引的分析、字幕/ASR、关键帧、价值判断 |
| 网页、微信公众号文章 | 可读文本提取、视觉证据、来源可信度检查 |
| 截图 / 图片 | OCR、视觉检查、布局分析 |
| 混合素材集 | 源地图、交叉验证分析 |

### 2. 试一个最小 prompt

```
用 gg-dailian 分析这个视频，输出时间轴证据、核心价值、可复用模式、下一步建议。
```

```
用 gg-dailian 提取这篇文章的核心观点，整理成知识笔记，标注证据边界。
```

### 3. 安装

把技能文件夹复制到你的 Agent 技能目录：

```bash
cp -r gg-dailian/ ~/.hermes/skills/
# 或
cp -r gg-dailian/ ~/.claude/skills/
```

## 技能架构

| 层 | 路径 | 用途 |
|----|------|------|
| 运行时入口 | `SKILL.md` | Agent 指令、触发条件、工作流、边界 |
| 方法论 | `references/` | 源类型路由、证据规则、产物规则、运行时排障 |
| 模板 | `templates/` | 可复用输出表单 |
| 示例 | `examples/` | 带来源/证据边界的参考输出 |
| 质量 | `evals/` | 回归测试 prompt 和预期行为 |
| 合约 | `contracts/` | 跨技能交接的共享 schema |
| 脚本 | `scripts/` | 媒体发现、网页分析、视频字幕、ASR 辅助 |

## 来源 → 价值管线

1. **快速观察**：低成本的初印象和价值判断
2. **深度拆解**：识别价值类型和来源运作方式
3. **价值阈值**：根据素材厚度决定产物规模
4. **产物转换**：把价值变成实践、模板、清单、SOP
5. **持久表达**：强结果打包成展示页、文档、知识笔记

## 使用场景

- 视频内容分析，带证据索引
- 网页研究，带视觉证据验证
- 截图 UI/UX 检查
- 混合素材竞品分析
- 散落素材的知识库策展
- 可分享展示页生成

## 设计原则

- 证据在观点之前
- 先用最便宜的可用证据
- 来源边界必须显式标注
- 产物格式匹配用户真实需求
- 证据不足时宁可标注 unknown，不猜不编
