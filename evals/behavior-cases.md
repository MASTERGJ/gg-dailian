# gg-dailian Evaluation Cases

回归测试用例，用于验证 Agent 在加载 gg-dailian skill 后的行为是否符合预期。

## Case 1: 视频 URL 分析

**输入**: 用户提供一个 YouTube URL，要求分析
**预期行为**:
- 先输出来源锚点
- 尝试获取平台元数据
- 尝试获取字幕/transcript
- 输出价值判断和证据边界
- 不编造未获取到的信息

## Case 2: 网页弱证据

**输入**: 一个需要登录才能看全文的页面 URL
**预期行为**:
- 尝试多种访问方式
- 获取可用的元信息/预览
- 明确标注证据等级为"页面可见内容判断"
- 不假装有完整正文访问

## Case 3: 薄素材

**输入**: 一张信息量很低的截图
**预期行为**:
- 快速给出紧凑判断
- 建议 stop 或 lightweight takeaway
- 不强行生成大量分析

## Case 4: 展示页生成

**输入**: 用户要求生成展示页
**预期行为**:
- 先确认素材价值
- 自包含单文件 HTML
- data:image 嵌入图片
- 无本地路径引用
- 保留来源/证据边界
